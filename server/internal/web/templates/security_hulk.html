cPHulk provides protection from brute force attacks against your web services.

Status: {{if not .V.Enabled}}Disabled {{else if and .Status (not (index .Status "Available"))}}Enabled (WhaCP sign-ins only: nftables is not installed) {{else}}Enabled{{end}} Watches WhaCP, webmail, SSH, IMAP/POP3, SMTP AUTH and FTP logins. {{len .Blocks}} block{{if ne (len .Blocks) 1}}s{{end}} in force.
Username-based Protection
Username-based protection tracks login attempts for user accounts. When disabled, cPHulk will not lock user accounts, but existing account locks will remain. Locked accounts cannot sign in to WhaCP until the lock ends.
Protection type
Also applies to WhaCP administrator accounts. When off, failures for them count toward IP address blocks only.
IP Address-based Protection
IP Address-based protection tracks login attempts from specific IP addresses. When disabled, cPHulk will not block IP addresses, but existing blocks will remain.

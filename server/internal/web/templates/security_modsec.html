ModSecurity: server-wide settings

Loads the rules once for all websites. Each website is then off, detection only or on (Websites tab); off here filters no website.
A request is blocked when the rules it matches add up to the threshold (a critical match counts 5). Higher: fewer false positives, less protection.
Websites set to “On” only log what they would block. Check the Recent events tab for false positives, then turn this off to start blocking.

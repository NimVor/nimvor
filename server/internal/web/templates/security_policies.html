This interface provides the configuration settings of the Security Policy that apply to WhaCP, WhaCP webmail, and on the server.

Security Policy Items
A WhaCP sign-in from an IP address the user has not verified needs a 6-digit code sent to the user's email address. Addresses users sign in from are remembered; when you turn this on, each user's last sign-in address counts as verified. Users without an email address can only sign in from verified addresses. On the server, sudo -u whacp -E php /opt/whacp/panel/bin/whacp user:verify-ip <user> <ip> verifies an address for a user.

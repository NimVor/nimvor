Host name

A fully qualified name such as server1.example.com. Point its DNS A record at this server before issuing its certificate. WhaCP updates /etc/hosts and, if mail is set up, the mail server for you. After a rename, find the old name left in DNS zones and configs.

Clock sync: {{$v.NTP}}.
{{if eq .User.RoleName "admin"}}

Root password

At least 14 characters with three of: lower case, upper case, digits, symbols. It is never logged or stored by WhaCP; SSH may still refuse root password logins by its own settings.
{{end}} {{if $v.DisplayManager}}

Graphical login screen

A server does not need a desktop login screen: turned off, GNOME Shell and its helpers no longer run (often 250–400 MB of memory). The server then boots to the text console; anyone signed in on the screen is signed out. SSH and the panel are not affected. Nothing is uninstalled.

Root shell

{{if not .Status.Enabled}} {{else if not .Status.RootAllowed}}

Root shells are off. A root shell in the browser means anyone who takes over an administrator's panel sign-in controls the whole server, so only the server's root user can allow it: set "terminal_root": true in /etc/whacp/agent.json and run systemctl restart whacp-agent.

Without it, use SSH as root, or open a website account's terminal from its website page.
